# Titel
Radiogids app voor het mediahuis

## Beschrijving
De radiogids app is ontwikkeld voor mensen die vershchillende radiozenders willen vergelijken of juist overzichtelijk kunnen zien wat er op een zender te zien is, verder heb ik de volgende gevraagde functies toegevoegd:

## Features

Overzicht van de verschillende programma’s voor een zender


Switchen van dagen

Switchen van radiostations

Klikken op de cards voor meer informatie

Tijdsindicatie die meeloopt met de huidige tijd

Overzicht van alle zenders per dag

## Extra feature:

Dark mode
Pwa (progressive web app)
